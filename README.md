## 프로젝트

프로젝트 이름을 누르면 작업 기록이나 저장소로 이동합니다.

- [**THING**](https://seminkong.github.io/SeMinKong_Web/work/thing/) — 손의 21개 landmark를 7축 명령으로 바꿔 텐던 로봇 핸드를 움직인 팀 프로젝트입니다.
- [**AQIS**](https://seminkong.github.io/SeMinKong_Web/work/aqis/) — RealSense와 YOLO 검사 결과를 컨베이어, Dobot, 운영 화면까지 연결한 스마트 팩토리 프로젝트입니다.
- [**Brain Tumor MRI**](https://seminkong.github.io/SeMinKong_Web/work/brain-tumor-mri/) — 종양 유형 분류와 영역 분할을 YOLO11로 실험하고, 마스크를 학습용 polygon으로 바꾸는 전처리를 구현했습니다.
- [**Project Prompt Generator**](https://seminkong.github.io/SeMinKong_Web/work/project-prompt-generator/) — 여섯 개의 설계 대화를 LangGraph 상태로 관리하고 결과를 하나의 구현 문서로 합치는 웹 도구입니다.
- [**Briefit**](https://seminkong.github.io/SeMinKong_Web/work/briefit/) — 뉴스를 비동기로 수집하고, 비슷한 기사를 묶어 KoBART로 요약하는 파이프라인입니다.
- [**Snake DQN**](https://github.com/SeMinKong/Snake_DQN) — CNN과 특징 벡터 기반 모델로 Snake를 학습시키며 DQN의 상태 표현을 비교한 실험입니다.
- [**TSP**](https://github.com/SeMinKong/TSP) — 유전 알고리즘과 simulated annealing을 PyTorch 텐서 연산으로 구현한 경로 탐색 프로젝트입니다.
